# Pomalo – Kroatisch lernen

Ein Kroatisch-Kurs für Ferien und Alltag: 150 Tageslektionen, über 1000 Wörter und 360 Alltagssätze, mit Grammatik, Hören und Nachsprechen.

**Auf dem Handy installieren:** Die Seite öffnen und dann
- **iPhone (Safari):** Teilen-Symbol › «Zum Home-Bildschirm»
- **Android (Chrome):** Menü ⋮ › «App installieren» oder «Zum Startbildschirm hinzufügen»

Die App funktioniert danach auch offline. Der Lernfortschritt wird auf dem jeweiligen Gerät gespeichert.

**Für den Ton** braucht das Gerät eine kroatische Stimme:
- iPhone: Einstellungen › Bedienungshilfen › Gesprochene Inhalte › Stimmen › Kroatisch
- Android: Einstellungen › Sprachausgabe › Google › Kroatisch installieren
